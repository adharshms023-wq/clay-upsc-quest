# UPSC Clay Studio

Build a production-ready, fully responsive UPSC Exam Preparation Platform using React, TypeScript, Tailwind CSS, Framer Motion, React Router, Lucide Icons, Context API, and Local Storage, following a clean, reusable component architecture that is ready for deployment on Vercel or Netlify. Design the entire application in a modern Claymorphism style with a premium, calming, distraction-free user experience optimized for long study sessions. Use a warm off-white background (#F8F8F6), large rounded corners (24–32px), soft outer and subtle inner shadows, floating 3D cards and buttons, minimal borders, generous whitespace, smooth 200–300ms micro-interactions, premium animations, WCAG-compliant accessibility, and a mobile-first responsive layout. Use the Poppins font with excellent typography, clean spacing, and minimal visual clutter. Follow a consistent color palette with Primary (#6FA8FF), Secondary (#A8E6CF), Accent (#FFD6A5), Success (#7FD8A5), Warning (#FFC857), Error (#FF8E8E), Background (#F8F8F6), and Text (#2E2E2E). Create a beautiful landing page featuring a hero section with the headline "Prepare for UPSC Smarter", a motivational subtitle, primary Start Learning and secondary Explore Syllabus call-to-action buttons, floating dashboard cards for UPSC Syllabus, Resources, Mock Tests, Previous Papers, Current Affairs, and Progress Tracker, along with animated statistics showing Study Streak, Topics Completed, Mock Tests Taken, and Weekly Progress. Build an interactive UPSC Syllabus section with separate Prelims and Mains modules using elegant accordion-based clay cards. The Prelims section should include History, Geography, Polity, Economy, Environment, Science & Technology, and Current Affairs, while the Mains section should include Essay, GS Paper I, GS Paper II, GS Paper III, GS Paper IV, and Optional Subjects. Each topic should support expandable content, progress tracking, completion checkboxes, study hours, personal notes, important resources, and automatic progress persistence using Local Storage. Develop a modern Resources Hub with searchable and filterable clay cards containing NCERT books, standard reference books, study notes, previous year question papers, current affairs, and revision materials, supporting search, subject filters, year filters, bookmarking, preview, download, and recently viewed functionality. Create a realistic Mock Test module with a distraction-free examination interface featuring a floating top bar displaying the exam name, countdown timer, question number, and progress bar, a centered clay question container with animated custom radio buttons, Previous, Next, Mark for Review, and Submit actions, and a color-coded question palette for Answered, Unanswered, Review, and Current questions. After submission, display a premium analytics dashboard showing overall score, percentage, estimated rank, accuracy, time taken, subject-wise analysis, weak areas, strong areas, performance graphs, and options to Review Answers, Download Report, and Retake Test. Include a comprehensive Progress Dashboard with daily, weekly, and monthly goals, learning streaks, completion heatmaps, study time analytics, subject-wise progress, and achievement badges. Add a minimalist Current Affairs module featuring daily updates, monthly PDF compilations, editorial notes, bookmarking, and read-later functionality. Implement a floating sticky navigation bar with Home, Syllabus, Resources, Mock Tests, Progress, and Profile sections, while mobile devices should use a floating bottom navigation. Finish the application with a clean footer containing About, Privacy Policy, Terms, and Contact links. Prioritize a clutter-free learning experience through excellent visual hierarchy, soft loading skeletons, elegant empty states, toast notifications, smooth page transitions, optimized performance, responsive layouts for mobile, tablet, and desktop, accessible design, reusable components, and a consistent Claymorphism design system. The final product should rival premium EdTech platforms such as Notion, Duolingo, and Headway in terms of design quality, usability, polish, and performance while maintaining a distinctive Claymorphism aesthetic tailored specifically for UPSC aspirants.
